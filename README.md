## 최신 결정

| 항목 | 현재 적용 |
|---|---|
| 남자 주인공 | 아르펜, 애칭 알. 과거 이름 에단 |
| 여자 주인공 | 확정 애칭 라피엔. 최근 결말 논의의 호칭 라피엘은 같은 인물로 연결해 기록. 정식 이름 후보는 아직 제안 |
| 북부 에덴 주민 | 공식 임시 명칭 초지성체. 과거 자료의 초인 표기를 현재 호칭으로 쓰지 않음 |
| 알의 아버지 | 시민을 살리려 항복한 집정관. 귀족 봉작 후 반란파 테러로 사망 |
| 이야기의 출발 | 알의 신분 은폐와 이방인 보육원 생활. 다른 아이들의 부모 추방·아이들 잔류 조건 반영 |
| 제국행 | 이후 영지 대표·볼모로 놓이며, 속죄·희생을 요구하는 설명을 주입받음 |
| 북부 밀약 | 추가 탈주 억제, 왕가의 서를 통한 정통성 지원, 연구 부작용·부산물 공동 대처 |
| 결말의 핵심 사건 | 알이 대목(Rootstock)이 되고 라피엔의 유전자가 알에게 접목됨 |
| 결말의 감정 갈등 | 라피엔은 사랑하는 알과의 아이를 원하고, 알은 그녀의 성장을 위한 튼튼한 뿌리가 되는 것으로 충분하다고 여김 |
| 부모의 계승 거부 | 남매의 부모는 황위 계승을 거부하며, 라피엔의 출생으로 자신들의 의무를 마침 |
| 황실 교체와 현 황제 | 기존 황실 일가의 테러 사망 뒤 황제가 교체됨. 아르켄의 옛 차남·대공 지위와 현 황제 지위는 기존 발언의 시점을 연결해 같은 인물의 이력으로 관리 |
| 조인식 당시 황태자 | 라피엔의 아버지. 가족 여행 중 조인식에 참석한 시점과 이후 레온의 황태자 시기를 구분 |
| 황실 차남의 역할 | 왕실의 호위 업무를 맡음. 레온의 황실 호위 선택은 이 역할 분담과 연결됨 |
| 황태자 레온 | 황태자의 의무를 다하려 제국의 문제들을 하나씩 해결하다가 이전 황실이 비밀리에 연구하던 결과를 알게 됨 |
| 남매의 계승 마찰과 레온의 선택 | 자기 유전자의 계승 부적합을 먼저 안 레온은 스스로 황태자직에서 물러나고, '차남'으로서 황실 호위에 남기로 함 |
| 라피엔의 계승 거부 | 황위를 계승하려면 알이 아닌 다른 사람과 결혼해야 하므로 거부함 |
| 최종 정치적 결말 | 위 거부·포기 사건은 확정. 이후의 최종 즉위·혼인·계승 조건 변경은 별도 설계 |

접목의 결말과 두 사람의 소망은 최신 사용자 결정으로 반영했다. 접목의 구체적 효과·대가, 실제 임신·출산과 감정적 해결은 별도 설계 사항이다. 자세한 갈등과 초반부터의 연결 제안은 [메인 줄거리](메인_줄거리_및_개연성.md)의 「대목과 사랑의 아이」에 정리했다.

계승의 갈림길은 같은 문서의 계승 거부 절에서 관리한다. 조인식 당시 아버지의 황태자 재임, 부모의 의무 완수와 계승 거부, 이후 황태자 레온의 조사·자진 사퇴, 라피엔의 혼인 조건에 따른 거부를 시점에 맞춰 읽는다. 라피엔 출생에 따른 의무 완수가 출생 당일의 자동 사퇴를 뜻하지는 않는다. 황실의 차남에게 호위 업무가 주어지는 역할 분담은 확정이며, 레온에게 적용하는 절차·지휘 범위와 비밀 연구의 구체적 결과는 후속 설계 대상이다.

기존 황실의 테러 사망과 황제 교체는 이미 설명된 역사다. 이전 갱신에서 아르켄의 아버지를 별도의 현 황제로 만들고 즉위 경위 전체를 미정으로 둔 설명은 정정했다. 근거와 수정 내용은 [변경이력 §1.5](설정_변경이력.md)에 기록한다.

## 설정을 적용하는 순서

1. 사용자가 직접 확정하거나 정정한 최신 결정을 우선한다.
2. 루트의 현행 문서에서 각 항목의 상태와 근거를 확인한다.
3. sources/의 원본은 과거 기록을 대조하는 자료로 사용한다. 최신 결정에 의해 변경된 이름이나 상태가 원본에 남아 있을 수 있다.
4. 문서의 작성일이 더 늦다는 이유만으로 제안이 확정되거나, 근거를 찾지 못한 항목이 미정으로 바뀌지는 않는다.
5. 원본 사이의 확정 수준 차이는 근거 확인 대상으로 남기고, 이미 정한 내용과 새 창작안을 구분한다.

### 상태 표기

- **확정·발언:** 사용자 직접 결정으로 확인한 내용.
- **확정·원본:** 참조 원본이 확정으로 기록한 내용.
- **기존 발언 복원·시점 연결:** 앞서 설명된 사건과 인물의 직위를 시점에 맞춰 연결한 내용. 여러 발언을 종합한 연결을 단일 발언의 직접 인용으로 취급하지 않는다.
- **기존 방향:** 기존 구상·가칭·잠정 연대.
- **제안:** 채택 전까지 정사가 아닌 보완안.
- **미정:** 아직 결정하지 않았다고 명시된 사항.
- **근거 확인 필요:** 기존 결정이 있을 수 있으나 자료가 부족하거나 문서가 다르게 기록한 사항.

## 다음 집필 전 확인할 부분

알의 나이와 사건 간격, 납치와 황실 테러의 상대 순서, 남매 부모와 아르켄의 정확한 혈통 연결, 복제품의 대응과 자기 인지, 조사병단장 비밀의 경계, 실제 방위 권한, 밀약의 상세 조건을 확인할 필요가 있다. 새 결말을 구체화할 때는 알이 대목이 될 수 있는 조건, 접목의 범위와 대가, 두 사람이 함께할 미래에 미치는 영향을 우선 설계한다.

구체적인 문제와 현재 처리 방식은 [설정 변경이력의 후속 확인 대장](설정_변경이력.md)에 정리했다. 인류사와 제국사, 형질과 황위 자격, 전투력과 유전적 적합성, 인물이 믿는 말과 세계의 실제 사실을 각각 구별해 집필한다.
